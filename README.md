# Матрицы комплексных чисел

Лабораторная работа на Java: сложение, умножение, деление, транспонирование матриц и вычисление определителя.

## Файлы

- `src/Complex.java` — комплексное число и операции над ним.
- `src/ComplexMatrix.java` — матрица и операции с матрицами.
- `src/Main.java` — консольное меню.

## Запуск

Нужен JDK 8 или новее. Откройте терминал в папке проекта и выполните:

```text
mkdir out
javac -encoding UTF-8 -d out src/Complex.java src/ComplexMatrix.java src/Main.java
java -Dfile.encoding=UTF-8 -cp out Main
```

## Использование

Создайте матрицы A и B через меню, укажите размеры и введите элементы. Затем выберите нужную операцию.

Каждый элемент вводится в отдельной строке: действительная и мнимая части через пробел. Например, `2 -3` означает `2 - 3i`. Букву `i` вводить не нужно. Дробные числа можно вводить с точкой или запятой.

Для транспонирования и определителя достаточно одной матрицы. Деление `A / B` вычисляется как `A * B⁻¹`, поэтому B должна быть квадратной и обратимой. Определитель считается методом Гаусса.

При неверном вводе или невозможной операции программа выводит сообщение об ошибке. Для выхода выберите `0`.
